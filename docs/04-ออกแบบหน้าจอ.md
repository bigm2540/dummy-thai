**หน้าหลัก (เต็มจอ) — 5:** 1) ล็อบบี้ 2) ห้องรอ 3) โต๊ะเล่นเกม 4) สรุปท้ายรอบ 5) สรุปเงินจบเกม *(mockup ครบแล้ว)*
**หน้าตั้งค่าห้อง (host สร้างห้อง):** เรท+เวลา 🟢 · คะแนน custom 🟡 *(mockup แล้ว ✅ — ดู §1.1)*
**ป๊อปอัป/โมดัล — 5:** 6) เลือกขุดเก็บกอง 🟢 · 7) โชว์สเปโต 🟡 · 8) host จัดการคนหลุด 🟢 · 9) ยืนยันปิดห้อง 🟢 · 10) **ตารางคะแนน+เงินรวมสด (กดดูทุกเมื่อ)** 🟢 — แตะที่คนใดคนหนึ่ง → ดู **ประวัติการคิดคะแนน** (ที่มาของได้/เสีย จาก ScoreEvent) กันทะเลาะ 🟢

> MVP 🟢 ≈ 9 จอ/ป๊อปอัป · ที่เหลือ 🟡/⚪ เพิ่มภายหลัง

## 0. Flow ของหน้าจอ

```
ล็อบบี้ → ห้องรอ → โต๊ะเล่นเกม → สรุปท้ายรอบ ──┐
                        ▲                        │ (host กดเริ่มรอบใหม่)
                        └────────────────────────┘
                   (host ปิดห้อง → สรุปเงินรวม → จบแมตช์)
```

---

## 1. หน้าล็อบบี้ (Lobby)
**เป้าหมาย:** เข้าเกม
- ช่องใส่ชื่อผู้เล่น
- ปุ่ม "สร้างห้องใหม่" (→ ไปห้องรอในฐานะ host)
- ช่องใส่รหัสห้อง + ปุ่ม "เข้าห้อง"

## 1.1 ตั้งค่าห้อง (Room Settings) — host เห็นตอนสร้างห้อง
**เป้าหมาย:** กำหนดกติกาเงิน/เวลา/คะแนนก่อนเปิดห้อง
- **หน่วยเงิน (เรท):** บาทต่อ 1 คะแนน — preset 1/5/10/20 หรือกำหนดเอง 🟢
  - แสดงตัวอย่างสด: "1 คะแนน = 5 บาท · น็อค +6 = +30฿ · โง่มืด −12 = −60฿"
- **เวลา:** เวลาต่อตา (ปิด/15/30/60 วิ) + เวลารอคนหลุด grace (30/60/120 วิ) 🟢
- **ค่าคะแนน custom (ขั้นสูง):** ปรับ ผู้ชนะ/เสีย/ตัวคูณ/โบนัส/บทลงโทษ + ปุ่มรีเซ็ตค่ามาตรฐาน 🟡
- ปุ่ม: "สร้างห้อง" / "ยกเลิก"

## 2. ห้องรอ (Waiting Room)
**เป้าหมาย:** รวมผู้เล่น 4 คน + ตั้งค่า
- แสดง **รหัสห้อง** (แตะคัดลอก/แชร์)
- 4 ที่นั่ง (ชื่อ/ว่าง, ระบุ host)
- สรุปการตั้งค่า: **เรทเงิน** (บาท/คะแนน) + **เวลาต่อตา**
- ปุ่ม "เริ่มเกม" (เฉพาะ host, ต้องครบ 4 คน)
- *(การตั้งเรท/เวลา host ทำในหน้านี้)*

## 3. โต๊ะเล่นเกม (Game Table) — จอหลัก · **แนวนอน (landscape)**

> ⚠️ อ้างอิงจากเกมดัมมี่จริงที่ผู้เล่นเล่น (ผู้เล่นส่งภาพมา)

**เป้าหมาย:** เล่นจริง — เล่นแนวนอน แบ่งโซนรอบจอ
- **ผู้เล่น 4 คนอยู่ขอบจอ:** 2 คนซ้าย + 2 คนขวา — แต่ละคนโชว์ ชื่อ + แต้ม (+/−P) + **จำนวนไพ่ในมือ** + ไฮไลต์คนที่ถึงตา
- **กลางจอแบ่งเป็น 4 โซน (มุมละคน) — ชุดที่เกิด "ของใครของมัน"** ✅ ไม่ใช่กองรวม! แต่ละคนวางตอง/เรียงในโซนของตัวเอง (ตรงกับ `Meld.ownerId` ใน data model) — เห็นของทุกคน เพราะฝากต่อกันได้
- **กองทิ้ง = แถบแดงคั่นกลาง เห็นไพ่ทุกใบ** (ไม่ใช่แค่ใบบนสุด) เพราะต้องเลือกขุด "เก็บกอง" ได้ ✅ + **กองจั่ว (คว่ำ + จำนวนเหลือ) อยู่ซ้ายสุดของแถบ**
- **ไพ่หัว มีมงกุฎ ♛ กำกับ** (ติดตามใบหัวจริงไม่ว่าจะอยู่ในกองทิ้งหรือถูกเกิดแล้ว) + เอฟเฟกต์เด้งตอนเกิดเหตุการณ์ (เช่น "ทิ้งปี้หัว −50P")
- **มือเรา (ล่างสุด):** ไพ่เรียงกดเลือกได้ (**สเปโตไฮไลต์**) + ปุ่มแอคชัน (แสดงตามสถานะ — ดู 3.1)

### 3.1 Logic การแสดงปุ่ม (ขับเคลื่อนด้วย `allowedActions` จากเซิร์ฟเวอร์)
| สถานะ | ปุ่มที่แสดง/กดได้ |
|-------|-----------------|
| ไม่ใช่ตาเรา | ไม่มีปุ่มแอคชัน |
| ตาเรา · ยังไม่จั่ว | **จั่ว** + **เก็บ** (เปิดเฉพาะถ้าขุดไปเกิด/ฝากได้จริง) |
| ตาเรา · จั่วแล้ว | **เกิด** (เลือกไพ่เป็นชุดถูก) · **ฝาก** (เกิดแล้ว+ต่อชุดได้) · **ทิ้ง** (เลือก 1 ใบ) · **น็อค** (ลงหมดเหลือใบปิด) |

- ปุ่มที่เงื่อนไขยังไม่ครบ → กดไม่ได้ (จาง) จนกว่าจะเลือกไพ่ถูก
- **เซิร์ฟเวอร์ตัดสินเสมอ** ว่าปุ่มไหนทำได้ (กันกดผิดกติกา/กันโกง)
- **แถบสถานะบน:** รอบที่/ทิศทาง/เดิมพัน + ไพ่หัว + **ตัวบอกตา + เวลานับถอยหลัง**

**สี/สัญลักษณ์ไพ่:**
- ดอกแดง (♥♦) ตัวอักษรแดง / ดอกดำ (♠♣) ตัวอักษรเข้ม
- **สเปโต (2♣ / Q♠) = เด่นพิเศษ** → ขอบทองหนา + พื้นทองอ่อน + ดาว ★ มุมบน (เห็นปุ๊บรู้ทันที)
- **ไพ่หัว = มงกุฎ ♛** ใต้ไพ่ (ติดตามใบหัวจริง)
- ไพ่ที่เลือกในมือ = ยกขึ้น + ขอบน้ำเงิน
- น็อค = ปุ่มเขียว (success)

## 4. สรุปท้ายรอบ (Round Summary)
**เป้าหมาย:** สรุปผล + ไปต่อ
- หัวข้อ "สรุปรอบ N" + เรทเงิน
- รายคน: ผล (น็อค/เสียน้อย/กลาง/มาก + เหตุพิเศษ เช่นโดนปี้), **คะแนนรอบนี้**, คะแนนสะสม, **เงิน**
- ผู้ชนะรอบไฮไลต์ (ขอบเขียว)
- ปุ่ม "เริ่มรอบใหม่" (host) · ปิดห้อง → ไปหน้าสรุปเงินจบเกม (4.1)

### 4.1 สรุปเงินจบเกม (Final Settlement) — ตอน host ปิดห้อง
**เป้าหมาย:** ปิดยอด + บอกว่าใครจ่ายใคร
- **อันดับสุดท้าย** — เรียง 1–4: คะแนนรวมทุกรอบ → เงินได้/เสีย (ผู้ชนะไฮไลต์ทอง, เหรียญอันดับ)
- **ป้ายสรุปว่าใครทำอะไร** (รวมจาก `ScoreEvent` ทั้งแมตช์) — เช่น น็อค ×3 · เกิดหัว ×2 · ฝากสเปโต ×2 · อมสเปโต ×1 · โดนโง่มืด ×1 (เขียว=ได้ / แดง=เสีย)
- **"ใครจ่ายใคร"** — สรุปการโอน (เช่น ปอ → โต้ง 60฿) เพื่อจ่ายเงินจริงได้เลย
- ยืนยัน **รวมทั้งวง = 0฿** (สมดุล)
- ปุ่ม: "เล่นเกมใหม่" / "ออกจากห้อง"

## 5. หลักการ UI
- **เล่นแนวนอน (landscape)** บนมือถือ — โต๊ะกว้าง เห็นกระดานชุดที่เกิด + กองทิ้งครบ
- **กองทิ้งเห็นทุกใบเสมอ** (จำเป็นต่อการเก็บกอง) · **ชุดที่เกิดของทุกคนเห็นหมด** (ฝากต่อกันได้)
- ปุ่มแตะง่าย, ไพ่กดเลือกได้
- เรียบ แบน ไม่มีเงา/ไล่สี (flat) — โทนเดียวกับเว็บทั่วไป
- ข้อมูลลับ (มือคนอื่น/กองจั่ว) แสดงแค่ "จำนวนใบ" ไม่โชว์หน้า (ตรงกับ PlayerView)
- รองรับ dark/light mode
