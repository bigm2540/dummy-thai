# การคิดเงิน (Scoring & Money) — เกมดัมมี่กินเงินไทย

> รวมระบบคิดคะแนน→เงินไว้ที่เดียว · **ทุกอย่าง zero-sum** (เงินรวมทุกรอบ = 0)
> อ้างอิง: [01-กติกาเกม.md](01-กติกาเกม.md) §7–9 · [02 ScoreConfig](02-ออกแบบ-data-model.md) §8

## 1. ภาพรวม 3 ชั้น

```
แต้ม (หน้าไพ่)   → ใช้จัดอันดับผู้แพ้เท่านั้น (เสียน้อย/กลาง/มาก)   [ไม่ใช่เงิน]
คะแนน            → ผลแพ้ชนะจริง = แพ้ชนะ(placement) + โบนัส − บทลงโทษ
เงิน             = คะแนนสะสม × เรทเงิน (บาท/คะแนน ที่ห้องตั้ง)
```

- **แต้มไพ่** (จัดอันดับ): 2-9=5, หัวสูง(10/J/Q/K)=10, A=15, สเปโต=50, ไพ่หัวที่เกิด=50/100
- **แต้มสุทธิ = แต้มที่เกิด − แต้มค้างมือ** → เรียงอันดับผู้แพ้ (สูงสุด=เสียน้อย, เท่ากันสุ่ม)
- **override:** คนโง่ + คนมืด (ไม่เกิดเลยทั้งรอบ) = **เสียมาก (−3) เสมอ** (หลายคน −3 เท่ากัน, คนน็อคเก็บผลรวม → zero-sum)

## 2. ตารางคะแนนทั้งหมด (zero-sum ทุกตัว ✅)

| รายการ | ผู้ทำ/ผู้ชนะ | ผู้เล่นคนอื่น | รวม |
|--------|------------|-------------|-----|
| **แพ้ชนะประจำรอบ** | คนน็อค **+6** | เสียน้อย/กลาง/มาก **−1/−2/−3** | 0 |
| **ตัวคูณน็อค** | มืด ×2 · สี ×2 · มืดสี ×4 | คูณทั้งสองฝั่ง | 0 |
| เกิดหัว | **+3** | −1 คนละ | 0 |
| เกิด/คว่ำสเปโต | **+3** | −1 คนละ | 0 |
| โบนัสใบปิด (ฝากได้/สเปโต) | **+3** | −1 คนละ | 0 |
| โชว์สเปโตครบ 2 ใบ | **+6** | −2 คนละ | 0 |
| ฝากสเปโตเข้าชุดคนอื่น | คนฝาก **+3** | เจ้าของชุด/คนวางใบก่อน **−3** | 0 |
| ฝากสเปโตเข้าชุดตัวเอง | คนฝาก **+3** | ทุกคน −1 คนละ | 0 |
| ทิ้งดัมมี่ / ทิ้งเต็ม | คนทิ้ง **−3** | ทุกคน +1 คนละ | 0 |
| ปี้ (ทั้งหัว+สเปโต / อย่างเดียว) | คนทิ้ง **−2/−1 ต่อคน** | ทุกคน +2/+1 | 0 |
| โง่ / โง่มืด / โง่มืดจนชนมืด | คนโง่ **−6/−12/−24** | คนน็อค +เท่ากัน | 0 |
| อมสเปโต (ถือไม่ลงจนจบ) | ผู้อม **−3** | ทุกคน +1 คนละ | 0 |

> 💡 ทุกแถวรวม = 0 → เงินไม่งอก/ไม่หาย เหมาะกับเกมกินเงิน

## 3. ตัวอย่างคำนวณ 1 รอบ (เรท 5 บาท/คะแนน)

**สถานการณ์:** A น็อค (ปกติ) · A เกิดหัว · D อมสเปโต (ถือ Q♠ ไม่ลง)
**อันดับผู้แพ้ (จากแต้มสุทธิ):** B เสียน้อย · C เสียกลาง · D เสียมาก

| คน | ที่มาของคะแนน | คะแนนรอบ | เงิน (×5) |
|----|--------------|---------|----------|
| **A** | น็อค +6, เกิดหัว +3, อมสเปโต(คนอื่น) +1 | **+10** | **+50฿** |
| **B** | เสียน้อย −1, เกิดหัว(คนอื่น) −1, อม +1 | **−1** | **−5฿** |
| **C** | เสียกลาง −2, เกิดหัว −1, อม +1 | **−2** | **−10฿** |
| **D** | เสียมาก −3, เกิดหัว −1, อมสเปโต(ผู้อม) −3 | **−7** | **−35฿** |
| | **รวม** | **0** ✅ | **0฿** ✅ |

---

## 3.1 ตัวอย่าง: รอบที่มี "โง่มืด" (เรท 5 บาท/คะแนน)

**เหตุการณ์:** A เกิดหัว · A ฝากสเปโต Q♠ เข้าชุด D · **B ทิ้งไพ่ → C เก็บไปน็อคมืด (B โง่มืด)**

| คน | ที่มา | คะแนน | เงิน |
|----|------|-------|------|
| A | เกิดหัว +3, ฝากสเปโต +3 | **+6** | +30฿ |
| B | เกิดหัว −1, **โง่มืด −12** | **−13** | −65฿ |
| C | เกิดหัว −1, **น็อคมืด +12** | **+11** | +55฿ |
| D | เกิดหัว −1, โดนฝากสเปโต −3 | **−4** | −20฿ |
| | **รวม** | **0** ✅ | 0฿ ✅ |

> โง่มืด = น็อคมืด(×2) → คนโง่จ่าย −12 แทนทั้งวง (A,D ไม่เสียส่วนโง่) + วนทิศ

## 4. สรุปเงินตอนจบแมตช์

- คะแนนสะสมข้ามรอบ (บวก/ลบสะสมไปเรื่อยๆ)
- host ปิดห้อง → **เงินรวมแต่ละคน = คะแนนสะสม × เรทเงิน**
- ผลรวมเงินทุกคน = 0 เสมอ (ใครได้เท่าไร มีคนเสียรวมเท่านั้น)
