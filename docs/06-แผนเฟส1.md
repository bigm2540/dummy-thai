## ภาพรวม 7 Milestone

```
M1 ติดตั้ง+สำรับไพ่ → M2 ชุดไพ่+เก็บกอง → M3 คะแนน → M4 เครื่องยนต์รอบ
   → M5 เน็ต+ห้อง → M6 หน้าเว็บ (เล่นกับเพื่อนได้!) → M7 เก็บงาน 🟡
```

> M1–M4 = game logic บริสุทธิ์ (เทสได้ไม่ต้องมีเน็ต) · M5–M6 = ต่อเน็ต+หน้าจอ · M7 = ความสมบูรณ์
