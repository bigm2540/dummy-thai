# เอกสารออกแบบ Data Model — เกมดัมมี่กินเงินไทย

> **เฟส 0 (ต่อ)** — ออกแบบโครงสร้างข้อมูลก่อนเขียนโค้ด
> เอกสารนี้เป็น "พิมพ์เขียว" ของข้อมูลในเกม — ยังไม่ใช่โค้ดจริง
> อ้างอิงกติกาจาก [01-กติกาเกม.md](01-กติกาเกม.md) เวอร์ชัน 2.4

---

## 0. หลักการออกแบบ

1. **Server-authoritative** — เซิร์ฟเวอร์เก็บ "ความจริง" ทั้งหมด (ไพ่ในมือทุกคน, กองจั่ว) ผู้เล่นเห็นเฉพาะข้อมูลที่ควรเห็น
2. **แยก "ข้อมูลลับ" ออกจาก "ข้อมูลสาธารณะ"** — มือผู้เล่นเป็นความลับ, ชุดที่เกิด/กองทิ้งเป็นสาธารณะ
3. **เก็บ "ใครวางไพ่ใบไหน"** — จำเป็นมากสำหรับกฎฝากสเปโต (ดูใบก่อนหน้า) และคิดแต้มสุทธิ
4. **เก็บ "ใครทิ้งไพ่ใบไหน + ตาที่เท่าไร"** — จำเป็นสำหรับ ปี้ / โง่
5. **ทุกค่าคะแนน custom ได้** — เก็บใน `ScoreConfig` แยกจาก logic

---

## 1. ภาพรวมความสัมพันธ์ (Entity Relationship)

```
Room (ห้อง)
 ├─ ScoreConfig (ตั้งค่าคะแนน — custom)
 ├─ Player[4] (ผู้เล่น)
 └─ Round (รอบที่กำลังเล่น)
     ├─ Stock (กองจั่ว)            ── Card[]
     ├─ DiscardPile (กองทิ้ง)       ── DiscardEntry[]  (อ้างถึง headCard)
     ├─ Meld[] (ชุดที่เกิดบนโต๊ะ)    ── MeldCard[]  (แต่ละใบจำ placedBy)
     ├─ PlayerHand[4] (ไพ่ในมือ)    ── Card[]  (ลับ)
     ├─ PlayerRoundState[4]         (hasMelded, เกิดอะไรไปบ้าง)
     └─ ScoreEvent[] (บันทึกคะแนนรอบนี้ → ใช้สรุปตอนจบ)
```

## 2. Card (ไพ่)

ไพ่ 1 ใบ — มี 52 ใบในเกม แต่ละใบไม่ซ้ำกัน

| ฟิลด์ | ชนิด | คำอธิบาย |
|------|------|---------|
| `id` | string | รหัสไม่ซ้ำ เช่น `"C2"` (2 ดอกจิก), `"SQ"` (Q โพดำ) |
| `suit` | Suit | ดอก: `SPADE`/`HEART`/`DIAMOND`/`CLUB` |
| `rank` | Rank | เลข: `2`–`10`, `J`, `Q`, `K`, `A` |

**ค่าที่คำนวณได้ (derived — ไม่ต้องเก็บ):**
| ค่า | กฎ |
|-----|-----|
| `isSpeto` | จริงถ้าเป็น `2♣` หรือ `Q♠` |
| `sortValue` | ลำดับเรียง: 2=2 … 10=10, J=11, Q=12, K=13, **A=14 (สูงสุด)** |
| `points(context)` | แต้มหน้าไพ่ — ขึ้นกับบริบท (ดูข้อ 2.1) |

### 2.1 แต้มของไพ่ (points) — ขึ้นกับบริบท
| บริบท | แต้ม |
|-------|------|
| ไพ่เลข 2–9 (ทั่วไป) | 5 |
| ไพ่ 10/J/Q/K (ทั่วไป) | 10 |
| A | 15 |
| **สเปโต (2♣/Q♠) ค้างมือตอนจบ** | 50 |
| **ไพ่หัวที่ถูกเกิด** | 50 (หรือ 100 ถ้าหัวเป็นสเปโต) |

> 💡 แต้มใช้สำหรับ **จัดอันดับผู้แพ้** เท่านั้น (แต้มสุทธิ = เกิด − ค้างมือ) ไม่ใช่คะแนนเงิน

```json
{ "id": "C2", "suit": "CLUB", "rank": "2" }
```

## 3. Meld (ชุดที่เกิด) + MeldCard

ชุดตอง/เรียงที่วางบนโต๊ะแล้ว

### Meld
| ฟิลด์ | ชนิด | คำอธิบาย |
|------|------|---------|
| `id` | string | รหัสชุด |
| `type` | MeldType | `SET` (ตอง) หรือ `RUN` (เรียง) |
| `ownerId` | playerId | เจ้าของชุด (คนที่เกิดชุดนี้คนแรก) |
| `cards` | MeldCard[] | ไพ่ในชุด **เรียงลำดับ** (สำคัญสำหรับเรียง) |
| `containsHead` | boolean | ชุดนี้มีไพ่หัวอยู่ไหม (เกิดหัว) |

### MeldCard
| ฟิลด์ | ชนิด | คำอธิบาย |
|------|------|---------|
| `card` | Card | ไพ่ใบนั้น |
| `placedBy` | playerId | **ใครเป็นคนวางใบนี้** (ตอนเกิด หรือ ฝาก) |

> 🔑 **ทำไมต้องเก็บ `placedBy` รายใบ:** กฎฝากสเปโต (8.3) ต้องดู "ใบก่อนหน้า" ว่าเป็นของใคร เพื่อตัดสินว่าใครเสีย −3 — ถ้าไม่เก็บรายใบจะคิดไม่ได้

```json
{
  "id": "meld_1", "type": "RUN", "ownerId": "p1", "containsHead": true,
  "cards": [
    { "card": {"id":"C2","suit":"CLUB","rank":"2"}, "placedBy": "p3" },
    { "card": {"id":"C3","suit":"CLUB","rank":"3"}, "placedBy": "p1" },
    { "card": {"id":"C4","suit":"CLUB","rank":"4"}, "placedBy": "p1" }
  ]
}
```

## 4. DiscardPile (กองทิ้ง) + DiscardEntry

กองไพ่หงายที่ซ้อนกัน — ลำดับสำคัญมาก (เก็บกอง + ไพ่หัวอยู่ก้นกอง)

### DiscardPile
| ฟิลด์ | ชนิด | คำอธิบาย |
|------|------|---------|
| `entries` | DiscardEntry[] | เรียงจาก **ก้นกอง (index 0) → บนสุด (ท้าย array)** |
| `headCardId` | string | id ของไพ่หัว (= `entries[0]` ตอนเริ่มเกม) |
| `headMelded` | boolean | มีคนเกิดหัวไปแล้วหรือยัง (เกิดได้ครั้งเดียว/รอบ) |

### DiscardEntry
| ฟิลด์ | ชนิด | คำอธิบาย |
|------|------|---------|
| `card` | Card | ไพ่ใบนั้น |
| `discardedBy` | playerId | **ใครทิ้งใบนี้** (สำหรับ ปี้ / โง่) |
| `turnNo` | number | ทิ้งในตาที่เท่าไร (สำหรับกรอบเวลา ปี้ = 1 ตา) |

> 🔑 **เก็บกอง:** ถ้าอยากได้ใบ index `i` ต้องหยิบ `entries[i ... ท้าย]` ทั้งหมด, ใบ `i` ต้องเอาไปเกิด/ฝากทันที, ที่เหลือเข้ามือ

```json
{
  "headCardId": "D3", "headMelded": false,
  "entries": [
    { "card": {"id":"D3",...}, "discardedBy": null, "turnNo": 0 },   // ไพ่หัว
    { "card": {"id":"H7",...}, "discardedBy": "p1", "turnNo": 1 },
    { "card": {"id":"SK",...}, "discardedBy": "p2", "turnNo": 2 }
  ]
}
```

## 5. Stock (กองจั่ว)

| ฟิลด์ | ชนิด | คำอธิบาย |
|------|------|---------|
| `cards` | Card[] | ไพ่คว่ำ เรียงจากบนสุด (index 0) ลงไป |

- จั่ว = เอา `cards[0]` ออก
- **กองจั่วหมด → จบรอบทันที** (ไม่สับกองทิ้งกลับ)

## 6. Player (ผู้เล่น)

ข้อมูลผู้เล่นระดับห้อง (อยู่ข้ามรอบ)

| ฟิลด์ | ชนิด | คำอธิบาย |
|------|------|---------|
| `id` | string | รหัสผู้เล่น |

| `connected` | boolean | กำลังเชื่อมต่ออยู่ไหม |
| `disconnectedAt` | timestamp \| null | เวลาที่หลุด (ใช้นับเวลา grace รอกลับมา) |

## 7. Round (สถานะรอบที่กำลังเล่น)

หัวใจของเกม — เก็บทุกอย่างของรอบปัจจุบัน

| ฟิลด์ | ชนิด | คำอธิบาย |
|------|------|---------|
| `roundNo` | number | รอบที่เท่าไร |
| `dealerSeat` | number | ที่นั่งเจ้ามือรอบนี้ |
| `turnNo` | number | นับตารวม (เพิ่มทุกครั้งที่จบตา) |
| `currentSeat` | number | ตาของใครตอนนี้ |
| `direction` | 1 \| -1 | ทิศทาง: 1=ปกติ, **-1=กลับด้าน (สลับเมื่อเกิดโง่)** |
| `phase` | TurnPhase | ช่วงในตา: `DRAW` → `ACTION` → `END` |
| `stock` | Stock | กองจั่ว |
| `discard` | DiscardPile | กองทิ้ง |
| `melds` | Meld[] | ชุดที่เกิดทั้งหมดบนโต๊ะ |
| `hands` | { [playerId]: Card[] } | ไพ่ในมือแต่ละคน (**ลับ**) |
| `playerStates` | { [playerId]: PlayerRoundState } | สถานะรายคนในรอบ |
| `pendingPee` | PeeWindow \| null | ใบล่าสุดที่ยังเสี่ยงโดนปี้ (กรอบ 1 ตา) |
| `turnDeadline` | timestamp \| null | ครบเวลาตานี้เมื่อไร (ถ้าตั้งจับเวลา) |
| `status` | RoundStatus | `PLAYING` / `ENDED` |
| `winnerId` | playerId \| null | คนน็อค (ถ้ามี) |
| `events` | ScoreEvent[] | บันทึกคะแนนที่เกิดในรอบนี้ |

### 7.1 PlayerRoundState (สถานะรายคนในรอบ)
| ฟิลด์ | ชนิด | คำอธิบาย |
|------|------|---------|
| `hasMelded` | boolean | เคย "เกิด" แล้วหรือยัง (ใช้เช็คสิทธิ์ฝาก + น็อคมืด) |
| `shownSpeto` | boolean | โชว์สเปโตครบ 2 ใบตอนเริ่มไปแล้วไหม |
| `roundScore` | number | คะแนนสะสมในรอบนี้ (รวม ScoreEvent ของคนนี้) |

### 7.2 PeeWindow (ติดตามสถานะปี้)
| ฟิลด์ | ชนิด | คำอธิบาย |
|------|------|---------|
| `cardId` | string | ไพ่ที่เพิ่งทิ้ง (เสี่ยงโดนปี้) |
| `discardedBy` | playerId | คนทิ้ง |
| `expiresAtTurn` | number | หมดอายุเมื่อถึงตานี้ (ทิ้ง +1 ตา) |

## 8. ScoreConfig (ตั้งค่าคะแนน — custom ตอนสร้างห้อง)

แยกค่าคะแนนทั้งหมดออกมา เพื่อให้ปรับได้โดยไม่แตะ logic

| ฟิลด์ | ค่าเริ่มต้น | ความหมาย |
|------|-----------|---------|
| `knockWin` | 6 | คะแนนผู้ชนะ (คนน็อค) |
| `lossTiers` | `[-1, -2, -3]` | เสียน้อย / กลาง / มาก |
| `knockMultiplier.normal` | 1 | น็อคปกติ |
| `knockMultiplier.dark` | 2 | น็อคมืด |
| `knockMultiplier.color` | 2 | น็อคสี |
| `knockMultiplier.darkColor` | 4 | น็อคมืดสี |
| `bonus.headMeld` | +3 / others −1 | เกิดหัว (zero-sum) |
| `bonus.spetoMeld` | +3 / others −1 | เกิด/คว่ำสเปโต (zero-sum) |
| `bonus.closeCardLayable` | +3 / others −1 | ใบปิดฝากได้ |
| `bonus.closeCardSpeto` | +3 / others −1 | ใบปิดเป็นสเปโต |
| `showSpeto.self` | +6 | โชว์สเปโตครบ 2 ใบ (คนโชว์) |
| `showSpeto.others` | -2 | โชว์สเปโต (คนอื่นเสียคนละ) |
| `spetoLayoff.self` | +3 | ฝากสเปโต (คนฝาก) |
| `spetoLayoff.victim` | -3 | ฝากสเปโตเข้าชุดคนอื่น (ผู้เสีย) |
| `spetoLayoff.ownMeldOthers` | -1 | ฝากสเปโตเข้าชุดตัวเอง (คนอื่นเสียคนละ) |
| `tingPenalty.self` | -3 | ทิ้งดัมมี่/ทิ้งเต็ม (คนทิ้ง) |
| `tingPenalty.others` | +1 | ทิ้งดัมมี่/ทิ้งเต็ม (คนอื่นได้คนละ) |
| `pee.both` | -2 | ปี้ทั้งหัว+สเปโต (จ่ายคนอื่นคนละ) |
| `pee.single` | -1 | ปี้อย่างเดียว (จ่ายคนอื่นคนละ) |
| `amSpeto.self` | -3 | อมสเปโต (ถือไม่ลงจนจบ — ผู้อม ต่อใบ) |
| `amSpeto.others` | +1 | อมสเปโต (ผู้เล่นคนอื่น ได้คนละ) |
| `ngoh.base` | -6 | โง่ (คนโง่จ่าย ก่อนคูณ) |
| `moneyRate` | 1 | เรทเงิน: บาทต่อ 1 คะแนน |

> หมายเหตุ: โง่ = `ngoh.base × knockMultiplier` ของการน็อคนั้น (โง่ −6, โง่มืด −12, โง่มืดจนชนมืด −24) จ่ายให้คนน็อคทั้งหมด

## 9. ScoreEvent (บันทึกคะแนน — สำหรับสรุปตอนจบ)

ทุกครั้งที่มีคะแนนเกิด/เสีย บันทึกเป็น event เพื่อให้ "สรุปแต้มตอนจบเกม" ทำได้ละเอียด

| ฟิลด์ | ชนิด | คำอธิบาย |
|------|------|---------|
| `type` | ScoreEventType | ประเภท (ดูด้านล่าง) |
| `playerId` | playerId | ใครได้/เสีย |
| `amount` | number | +/- คะแนน |
| `turnNo` | number | เกิดตาที่เท่าไร |
| `note` | string | คำอธิบายสั้น (เช่น "เกิดหัว 3♣") |

**ScoreEventType:** `SHOW_SPETO` · `HEAD_MELD` · `SPETO_MELD` · `SPETO_LAYOFF` · `CLOSE_CARD_BONUS` · `KNOCK_WIN` · `LOSS_RANK` · `TING_DUMMY` · `TING_TEM` · `PEE` · `NGOH` · `AM_SPETO`

```json
{ "type": "HEAD_MELD", "playerId": "p1", "amount": 1, "turnNo": 5, "note": "เกิดหัว 3♣" }
```

## 12. Action (การกระทำของผู้เล่นในแต่ละตา)

ผู้เล่นส่ง action มาให้เซิร์ฟเวอร์ตรวจและประมวลผล (รายละเอียด protocol จะออกแบบในเฟส 1)

| Action | ข้อมูลที่ส่ง | ทำในช่วง |
|--------|------------|---------|
| `SHOW_SPETO` | — | ก่อนเริ่ม (ถ้าได้ครบ 2 ใบ) |
| `DRAW_STOCK` | — | DRAW |
| `PICK_DISCARD` | `targetIndex` | DRAW (เก็บกอง) |
| `MELD` | `cards[]`, `type` | ACTION |
| `MELD_HEAD` | `cards[]` | ACTION (ต้องดึงใบหัว) |
| `LAYOFF` | `cards[]`, `meldId` | ACTION (ต้องเกิดก่อน) |
| `DISCARD` | `cardId` | END |
| `KNOCK` | `faceDownCardId` | END |

## 13. จุดที่ต้องระวังตอนเขียนโค้ด (mapping ↔ กติกา)

| กติกา | ข้อมูลที่ใช้ |
|-------|------------|
| ฝากสเปโตดู "ใบก่อนหน้า" เป็นของใคร | `MeldCard.placedBy` (รายใบ) |
| ปี้ / โง่ ว่าใครทิ้ง + กรอบ 1 ตา | `DiscardEntry.discardedBy` + `turnNo` + `pendingPee` |
| น็อคมืด (ไม่เคยเกิด) | `PlayerRoundState.hasMelded` |
| คนมืด (บังคับเสียมาก) | `!hasMelded` ตอนจบรอบ → ล็อกเป็นเสียมาก −3 |
| โง่ → กลับทิศ | `Round.direction` (สลับ 1 ↔ -1) |
| เกิดหัวได้ครั้งเดียว | `DiscardPile.headMelded` |
| แต้มสุทธิ (เกิด − ค้างมือ) | sum แต้มจาก `melds` (ตาม placedBy) − sum มือ |
| ทิ้งดัมมี่/ทิ้งเต็ม คิดทันที | ตรวจ `DISCARD` กับ `melds` + `hands` คนอื่น |
| สรุปแต้มตอนจบ | รวม `Round.events` ต่อคน |

## 14. เพิ่มเติมสำหรับเล่นออนไลน์

### 14.1 RoomSettings (ตั้งค่าห้อง — นอกเหนือจากคะแนน)
| ฟิลด์ | ค่าเริ่มต้น | คำอธิบาย |
|------|-----------|---------|
| `turnTimeLimitSec` | `null` | เวลาต่อตา (วินาที); `null` = ไม่จับเวลา ✅ |
| `disconnectGraceSec` | 60 | เวลารอผู้เล่นที่หลุดให้กลับมา ✅ |
| `dealerRotation` | `CLOCKWISE` | หมุนเจ้ามือ: รอบถัดไปเลื่อนที่นั่ง +1 |

### 14.2 ระบบรอบ & การจบแมตช์ ✅
```
เริ่มรอบ → เล่นจนน็อค/กองหมด → จบรอบ
   → แสดง "หน้าสรุปรอบ" (RoundSummary: ใครได้/เสียเท่าไร + คะแนนสะสม)
   → host กด "เริ่มรอบใหม่" (awaitingNextRound = false → รอบถัดไป, หมุนเจ้ามือ)
   → ... วนไปเรื่อยๆ ...
แมตช์จบเมื่อ: host (แอดมิน) กดปิดห้อง → สรุปเงินรวมทั้งหมด → Room.status = FINISHED
```

### 14.3 RoundSummary (หน้าสรุปท้ายรอบ)
| ฟิลด์ | ชนิด | คำอธิบาย |
|------|------|---------|
| `roundNo` | number | รอบที่เท่าไร |
| `rows` | SummaryRow[] | สรุปรายคน |

**SummaryRow:** `playerId` · `roundScore` (คะแนนรอบนี้) · `breakdown` (รายการ ScoreEvent ของคนนี้) · `totalScore` (สะสม) · `money` (= total × moneyRate)

### 14.4 PlayerView (ข้อมูลที่ส่งให้ client แต่ละคน) 🔒
เซิร์ฟเวอร์ **ไม่ส่ง state ดิบ** ออกไป แต่ส่ง "view" เฉพาะของผู้เล่นคนนั้น เพื่อกันโกง:
| ส่งไป | รายละเอียด |
|-------|-----------|
| มือ **ตัวเอง** | เห็นไพ่จริง |
| มือ **คนอื่น** | เห็นแค่ **จำนวนใบ** (ไม่เห็นหน้า) |
| กองจั่ว | เห็นแค่ **จำนวนใบ** (ไม่เห็นหน้า) |
| กองทิ้ง / ชุดที่เกิด / คะแนน | เห็นทั้งหมด (สาธารณะ) |
| **allowedActions** | **รายการปุ่มที่กดได้ตอนนี้** (server คำนวณตามตา/ขั้น/กติกา) → client แสดง/เปิดเฉพาะอันนี้ |

> 🔒 หลักการ: ไพ่ลับ (มือคนอื่น + กองจั่ว) **ห้ามออกจากเซิร์ฟเวอร์** เด็ดขาด

### 14.4.1 กันโกง (เว็บ inspect ง่าย) 🛡️
**inspect/แก้เบราว์เซอร์ โกงไม่ได้ เพราะ logic+ไพ่อยู่ที่เซิร์ฟเวอร์:**
1. **ไพ่ลับไม่เคยส่งไป client** (PlayerView) → inspect ก็ไม่เห็นไพ่คนอื่น/กองจั่ว
2. **เซิร์ฟเวอร์ตรวจทุก action** (เป็นตาเขาไหม/มีไพ่จริงไหม/ถูกกติกาไหม) → action ปลอมถูกปฏิเสธ
3. **คะแนน/เงินคิดที่เซิร์ฟเวอร์** → แก้ตัวเลขในจอไม่กระทบของจริง
4. **token ลับ** (กันปลอมตัว) + **HTTPS** (กันดักจับ) + validate/ratelimit ทุก input
- ⚠️ กันไม่ได้: **สมรู้ร่วมคิด** (เพื่อนบอกไพ่กันนอกเกม) — เป็นเรื่องความไว้ใจ (เล่นกับเพื่อนโอเค)
> 🎛️ ปุ่มแอคชันขับเคลื่อนด้วย `allowedActions` — ดูเงื่อนไขในเอกสารหน้าจอ ([04](04-ออกแบบหน้าจอ.md))

### 14.5 หลุด & กลับเข้าเกม (Reconnection) 🟢 *สำคัญ — เป็น MVP*

**หลักการ:** state อยู่ที่เซิร์ฟเวอร์ → เพื่อนหลุดเกมไม่หาย แค่ต้องจำได้ว่าใครกลับมา (ใช้ `token`)

```
หลุด → socket disconnect → connected=false, disconnectedAt, เริ่มจับ grace
        (เก็บที่นั่ง+มือไพ่ไว้ครบ ไม่ลบ) · คนอื่นเห็น "⏳ กำลังกลับมา…"
กลับ → client ต่อใหม่ (socket.io auto) → ส่ง rejoin{roomCode, token}
     → server เจอ token → ผูก socket ใหม่เข้าที่นั่งเดิม → ส่ง PlayerView ปัจจุบัน → เล่นต่อ ✅
```

- **ตาเขาขณะหลุด:** ตั้งเวลาต่อตา → ครบเวลา auto (จั่ว+ทิ้ง); ไม่ตั้ง → รอ
- **เกิน grace ยังไม่กลับ:** เด้ง popup ให้ **host เลือก → รอต่อ / จบแมตช์** ✅
  - *รอต่อ:* คอยต่อ (ผู้เล่นยัง rejoin ได้ตลอด)
  - *จบแมตช์:* เพราะเล่น 4 คน ขาดคน → เล่นต่อไม่ได้ → ไปหน้าสรุปเงินจบเกมเลย
- **รีเฟรชหน้า (F5):** = หลุด+ต่อใหม่ → token ใน localStorage พากลับเข้าเกมเดิม
- 💾 **กันเซิร์ฟเวอร์หลับ/รีสตาร์ท:** เซฟ state ลง **ที่เก็บภายนอก (DB/Redis)** — *ไม่ใช่ไฟล์ในเครื่อง เพราะ host ฟรี disk หายตอนรีสตาร์ท* — แล้วโหลดกลับตอนเปิด → กู้เกมคืน (งาน M7) 🟡

### 14.6 หมายเหตุเรื่องปี้ (ปิดช่องคลุมเครือ)
- `pendingPee` เก็บแค่ **ใบล่าสุด** ก็พอ เพราะปี้มีกรอบแค่ **1 ตา** → ขุดไพ่เก่า (ทิ้งไว้นาน > 1 ตา) ไปเกิดหัว/สเปโต **ไม่นับเป็นปี้** ✅
