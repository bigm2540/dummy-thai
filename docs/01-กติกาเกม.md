# เอกสารกติกาเกมดัมมี่ (ดัมมี่กินเงินไทย)

> **เฟส 0** — เอกสารนี้คือ "สมองของเกม" ทุกข้อจะถูกแปลงเป็นโค้ดในเฟสถัดไป
> สถานะ: 🟢 **เวอร์ชัน 2.5 — ล็อกครบ ตรวจความสอดคล้องแล้ว** พร้อมเข้าเฟส 1
> อ้างอิง: กติกามาตรฐานดัมมี่กินเงินไทย (research) + ที่ผู้เล่นกำหนด

## 0. แนวคิดสำคัญ: 2 หน่วยที่ต้องแยกกัน

| หน่วย | ใช้ทำอะไร | ค่า |
|------|----------|-----|
| **แต้ม** (points) | ค่าหน้าไพ่ ใช้ **จัดอันดับผู้แพ้** เท่านั้น | 2-9=5, หัวสูง(10/J/Q/K)=10, A=15, สเปโต=50, **ไพ่หัวที่เกิด=50 (100 ถ้าเป็นสเปโต)** |
| **คะแนน** (score) | หน่วยที่ได้/เสียจริง → **แปลงเป็นเงิน** | +6/−1/−2/−3, +3, −6 ฯลฯ |

> 📌 **แต้มสุทธิ = (แต้มไพ่ที่เกิดบนโต๊ะ) − (แต้มไพ่ค้างมือ)** → ใช้เรียงอันดับว่าใครเสียน้อย/กลาง/มาก
> ส่วน **คะแนน** คือสิ่งที่บันทึกเป็นผลแพ้ชนะจริง

## 1. ภาพรวม

- **ประเภท:** เกมไพ่ผลัดกันเล่น แนวดัมมี่กินเงินไทย
- **ผู้เล่น:** **4 คนเท่านั้น** ✅ (เกมนี้รองรับเฉพาะ 4 คน)
- **สำรับ:** 52 ใบ — **ไม่ใช้โจ๊กเกอร์** ✅
- **ชื่อดอก:** ♠ โพดำ / ♥ โพแดง / ♦ ข้าวหลามตัด / ♣ ดอกจิก

## 2. ไพ่พิเศษ

### 2.1 สเปโต (2 ใบ)
- **2♣ (2 ดอกจิก)** และ **Q♠ (ควีนโพดำ)** — ไพ่แต้มสูงสุด เกิด/คว่ำได้แต้มพิเศษ
- **โชว์สเปโต:** ถ้าได้ **ครบทั้ง 2 ใบตอนแจก** → โชว์รับโบนัสได้ (ดูข้อ 8.3)

### 2.2 ไพ่หัว
- ไพ่ใบบนสุดที่ **เปิดหงายตอนเริ่มเกม** (ใบเดียวกับกองทิ้งเริ่มต้น) → เป็น "ก้นกอง" ของกองทิ้ง
- **เกิดหัว = ต้องดึงใบหัวใบจริงออกจากก้นกองทิ้ง (ใช้กฎเก็บกอง) มาเข้าชุด** ✅ ไม่ใช่แค่ไพ่เลขตรงกัน
  - ⚠️ หัวอยู่ก้นกอง → ต้อง **ขุดไพ่ทั้งกองที่ทับอยู่ขึ้นมาด้วย** (ยิ่งเล่นนาน ยิ่งขุดยาก) ✅
- เกิดหัวได้ → **+1 คะแนน** และไพ่หัวนับ **50 แต้ม** ตอนจัดอันดับ
- **ถ้าไพ่หัวเป็นสเปโต → ×2** (หัว = 100 แต้ม + ได้ทั้งคะแนนเกิดหัวและสเปโต) ✅
- เกิดหัวได้ **ครั้งเดียวต่อรอบ** (มีใบหัวใบเดียว)

## 3. ศัพท์ในเกม

| คำ | ความหมาย |
|----|----------|
| **เกิด** | ลงไพ่ (วางตอง/เรียงบนโต๊ะ) |
| **เกิดหัว** | เอาไพ่ที่ตรงกับไพ่หัวมาเกิด → แต้มพิเศษ |
| **ฝาก** | เอาไพ่ต่อเข้าชุดที่เกิดแล้ว (ของตัวเอง/คนอื่น) |
| **ใบปิด** | ไพ่ใบสุดท้ายที่ **คว่ำ** ไว้ตอนน็อค |
| **น็อค** | ลงไพ่หมดมือ เหลือใบปิด 1 ใบ → ชนะรอบ |
| **น็อคมืด** | น็อคโดยไม่เคยเกิดมาก่อนเลย (ลงรวดเดียวจบ) |
| **น็อคสี** | น็อคโดยไพ่ที่ลงเป็นดอกเดียวล้วน |
| **น็อคมืดสี** | น็อคมืด + น็อคสี พร้อมกัน |
| **ปี้** | ทิ้งไพ่ที่คนอื่นเก็บไปเกิดหัว/สเปโตได้ → คนทิ้งโดนปรับ |
| **ทิ้งดัมมี่** | ทิ้งไพ่ที่คนอื่นฝากเข้าชุดที่มีอยู่แล้วได้ → คนทิ้งโดนปรับ |
| **ทิ้งเต็ม** | ทิ้งไพ่ที่ **รวมกับไพ่ในกองทิ้ง เป็นตอง/เรียงได้** → คนทิ้งโดนปรับ |
| **โง่** | ทิ้งไพ่แล้วคนถัดไปเก็บไปน็อค → คนทิ้งโดนปรับหนัก |
| **อมสเปโต** | ถือสเปโต (2♣/Q♠) ไว้ไม่ลงจนจบรอบ → โดนปรับ |
| **คนมืด** | ผู้เล่นที่ไม่ "เกิด" เลยตลอดทั้งรอบ (ถือไพ่เต็มมือ) |

## 4. การเริ่มเกม

1. สับไพ่ 52 ใบ
2. **เจ้ามือแจกไพ่** (เริ่มจากเจ้ามือก่อน) คนละ **7 ใบ** (เล่น 4 คน) ✅
3. ไพ่ที่เหลือวางคว่ำเป็น **กองจั่ว**
4. **เปิดไพ่ใบบนสุด 1 ใบ** → เป็นทั้งกองทิ้งเริ่มต้น และ **ไพ่หัว**
5. **โชว์สเปโต:** ผู้เล่นที่ได้ **สเปโตครบ 2 ใบ (2♣ + Q♠)** ตอนแจก → โชว์รับโบนัสได้ (ข้อ 8.3)
6. **เจ้ามือเล่นเป็นคนแรก**

## 5. ลำดับการเล่นในแต่ละตา (Turn)

### ขั้น 1 — จั่วไพ่ (บังคับเลือก 1 อย่าง)
- **จั่วจากกองจั่ว** — หยิบใบบนสุด (ไม่เห็นหน้า) เข้ามือ  หรือ
- **เก็บจากกองทิ้ง** — ตามกฎเก็บกอง (ข้อ 5.1)

### ขั้น 2 — เกิด (ไม่บังคับ ทำได้หลายชุด)
- วางตอง/เรียงจากไพ่ในมือลงโต๊ะ
- ตรงกับไพ่หัว → "เกิดหัว" (+คะแนน) | เป็นสเปโต → +คะแนน

### ขั้น 3 — ฝาก (ไม่บังคับ)
- ต่อไพ่เข้าชุดที่เกิดแล้วบนโต๊ะ (ของตัวเอง/คนอื่น)
- **ต้องเกิดชุดของตัวเองอย่างน้อย 1 ครั้งก่อน ถึงจะฝากได้** ✅ (มาตรฐาน)
- ฝากสเปโตเข้าชุดคนอื่น → เราได้ คนโดนฝากเสีย (ข้อ 8.3)

### ขั้น 4 — จบตา (เลือก 1 อย่าง)
- **ทิ้งไพ่ 1 ใบ** ลงกองทิ้ง → ส่งตาให้คนถัดไป  หรือ
- **น็อค** — ลงไพ่หมด เหลือ 1 ใบเป็นใบปิด (คว่ำ) → จบรอบ (ข้อ 7)

> ⚠️ ระวังการทิ้งไพ่ที่คนอื่นใช้ได้ → อาจโดน **ทิ้งเต็ม / ปี้ / โง่** (ข้อ 9)
> 📝 ทิ้งใบที่เพิ่ง **จั่ว** ได้ตามปกติ · แต่ใบ **"เป้าหมาย" ที่ขุดมาจากกองทิ้ง ต้องเอาไปเกิด/ฝาก (ทิ้งไม่ได้)**

### 5.1 กฎเก็บกอง ✅
- ขุดเอาไพ่ในกองทิ้งได้ลึกแค่ไหนก็ได้ แต่ต้องหยิบทุกใบตั้งแต่ใบเป้าหมายถึงใบบนสุด
- **ใบเป้าหมายต้องเอาไปเกิด/ฝากทันที** | ใบอื่นเก็บเข้ามือได้
- ตัวอย่าง: กอง `[1][2][3][4][5]` อยากได้ `[3]` → หยิบ `[3][4][5]`, ลง `[3]`, เก็บ `[4][5]`

## 6. ชุดไพ่ที่เกิดได้

- **ตอง (Set):** เลขเดียวกัน 3 ใบขึ้นไป ต่างดอก — ♠7 ♥7 ♦7

  - 📝 *หมายเหตุ: ต่างจากดัมมี่ไทยส่วนใหญ่ที่ A เป็นตัวต่ำ (A-2-3) — ผู้เล่นตั้งใจให้ต่าง*

## 7. การน็อค (จบรอบ)

- น็อค = ลงไพ่หมดมือ **เหลือ 1 ใบเป็นใบปิด (คว่ำ) เสมอ** → ชนะทันที ✅
- *"น็อคชนะเลย ไม่ต้องนับแต้มแข่งกับใคร"*

### โบนัสใบปิด ✅
- ใบปิดเป็นไพ่ที่ **ฝากคนอื่นได้** (ต่อชุดบนโต๊ะได้) → คนน็อค **+3** / คนอื่น **−1** คนละ
- ใบปิดเป็น **สเปโต** → คนน็อค **+3** / คนอื่น **−1** คนละ

### ประเภทน็อค (ตัวคูณคะแนนผู้ชนะ)
| ประเภท | เงื่อนไข | ตัวคูณ |
|--------|---------|--------|
| น็อค | ปกติ | ×1 |
| น็อคมืด | ไม่เคยเกิดมาก่อน ลงรวดเดียว | ×2 |
| น็อคสี | ไพ่ที่ลงดอกเดียวล้วน | ×2 |
| น็อคมืดสี | มืด + สี | ×4 |

## 8. ระบบคะแนน

### 8.1 คะแนนแพ้-ชนะประจำรอบ (Layer A — custom ได้)
จัดอันดับผู้แพ้ตาม **แต้มสุทธิ (เกิด − ค้างมือ)** จากมากไปน้อย (เล่น 4 คน → ผู้แพ้ 3 คนพอดี):

| อันดับ | ใคร | คะแนน |
|--------|-----|-------|
| ผู้ชนะ | คนน็อค | **+6** ✅ |
| เสียน้อย | แต้มสุทธิสูงสุด (ในผู้แพ้) | **−1** |
| เสียกลาง | อันดับกลาง | **−2** |
| เสียมาก | แต้มสุทธิน้อยสุด/ติดลบมากสุด | **−3** |

- **บังคับเสียมาก (override):** ✅ **คนโง่** และ **คนมืด** (ไม่เกิดเลยทั้งรอบ) → เป็น **เสียมาก (−3) เสมอ** ไม่ว่าแต้มสุทธิจะดีแค่ไหน
  - มีหลายคนเข้าข่าย → **−3 เท่ากันทุกคน** | ที่เหลือเรียงตามแต้มสุทธิลงช่องที่เหลือ (เริ่มจากเสียน้อย)
  - คนน็อคได้ = **ผลรวมที่ผู้แพ้ทุกคนเสีย** (ให้ zero-sum เสมอ)
- **แต้มสุทธิเท่ากัน → สุ่มการ์ดตัดสิน** (เท่ากัน 2 คน → สุ่ม 2 คน) ✅
- ตัวคูณน็อค (ข้อ 7) **คูณทั้งฝั่งผู้ชนะและผู้แพ้** ✅ เช่น น็อคมืด (×2): ผู้ชนะ **+12** / ผู้แพ้ **−2 / −4 / −6** (ยัง zero-sum)

### 8.2 กองจั่วหมด — "ตาสุดท้าย" ✅
- คนที่ **จั่วไพ่ใบสุดท้าย** ของกองจั่ว เล่นตาตามปกติ (น็อค/ทิ้ง)
- ถ้าเขา **ไม่น็อค (ทิ้ง)** → **คนถัดไปได้เล่นตาสุดท้าย 1 ตา** เท่านั้น:
  - จั่วไม่ได้ (กองหมด) → ทำได้แค่ **เก็บไพ่จากกองทิ้ง แล้วน็อค**
  - น็อคได้ → จบรอบแบบมีคนน็อค (คิดคะแนนปกติ)
  - **น็อคไม่ได้/ไม่น็อค → จบรอบทันที** จัดอันดับทุกคนตามแต้มสุทธิ คนสูงสุดชนะ
- ไม่สับกองทิ้งกลับเป็นกองจั่ว
- 📝 *M4a ทำแบบง่ายไว้ก่อน (กองหมด→จบทันที) → M4b จะใส่ "ตาสุดท้าย" ให้ครบ*

### 8.3 แต้มพิเศษระหว่างรอบ (Layer B — คะแนน บวกแยกต่างหาก) ✅
| เหตุการณ์ | คะแนน |
|----------|-------|
| **โชว์สเปโตครบ 2 ใบ (ตอนแจก)** | คนโชว์ **+6** / ผู้เล่นคนอื่น **เสียคนละ 2** |
| เกิดหัว | คนทำ **+3** / ผู้เล่นคนอื่น **−1** คนละ |
| เกิด/คว่ำสเปโต (2♣ / Q♠) | คนทำ **+3** / ผู้เล่นคนอื่น **−1** คนละ |
| ฝากสเปโตเข้าชุด **คนอื่น** | คนฝาก **+3** / ผู้เสีย **−3** |
| ฝากสเปโตเข้าชุด **ตัวเอง** | คนฝาก **+3** / ผู้เล่นคนอื่น **ทุกคน เสียคนละ 1** (จ่ายให้คนฝาก) |

**กฎ "ใครเสีย" เมื่อฝากสเปโตเข้าชุดคนอื่น (−3):**
- ดูไพ่ **ใบก่อนหน้า** (ใบที่สเปโตไปต่อ) ในชุดนั้น
- ถ้าใบก่อนหน้าเป็นของ **คนที่ฝากมาก่อน (คนอื่น)** → คนนั้นเสีย −3
- ถ้าใบก่อนหน้าเป็นของ **เจ้าของชุดเอง** → เจ้าของชุดเสีย −3

## 9. บทลงโทษจากการทิ้งไพ่ให้คนอื่น

> 📌 **เวลาคิดโทษ:**
> • **ทิ้งดัมมี่ / ทิ้งเต็ม → คิดทันทีตอนทิ้ง** ✅ (ระบบตรวจว่าไพ่ที่ทิ้งใช้ได้ไหม ไม่ต้องรอใครเก็บ)
> • **ปี้ / โง่ → คิดเมื่อมีคนเอาไพ่ที่ทิ้งไปใช้จริง** (ปี้ = เกิดหัว/สเปโต, โง่ = น็อค — ใครก็ได้ที่ขุดไปใช้)
> 📌 **ซ้อนกันได้ — รวมโทษทุกอัน** ✅ เช่น ทิ้งสเปโตแล้วมีคนขุดไปเกิดหัว+สเปโต แล้วน็อค = ทิ้งเต็ม + ปี้(หัว+สเปโต) + โง่ บวกกันหมด

ระดับความรุนแรง (เบา → หนัก):

### 9.1 ทิ้งดัมมี่ / ทิ้งเต็ม (คิดทันทีตอนทิ้ง)
- **ทิ้งดัมมี่:** ทิ้งไพ่ที่คนอื่น **ฝากเข้าชุดที่มีอยู่แล้ว** บนโต๊ะได้
- **ทิ้งเต็ม:** ทิ้งไพ่ที่ **รวมกับไพ่ในกองทิ้ง เกิดเป็นตอง/เรียงได้** (มีชุดสมบูรณ์ในกองทิ้งให้ขุด)
- ทั้งคู่: **คนทิ้ง −3 / ผู้เล่นคนอื่น +คนละ 1** ✅
- **คิดทันทีตอนทิ้ง จากข้อมูลสาธารณะ** ✅
  - ทิ้งดัมมี่ → เช็คกับ **ชุดที่เกิดบนโต๊ะ** (ใบที่ทิ้งฝากได้ไหม)
  - ทิ้งเต็ม → เช็คกับ **กองทิ้ง** (ใบที่ทิ้ง + กองทิ้ง เป็นตอง/เรียงไหม)
  - *ไม่ต้องดูมือคู่แข่ง → ใช้ `isValidSet/isValidRun/canLayOff` ซ้ำได้*

### 9.2 ปี้ (ทิ้งให้เกิดหัว/สเปโต)
- ทิ้งไพ่ที่คนอื่นเก็บไป **เกิดหัว** หรือ **เกิดสเปโต** ได้
- ตัวอย่าง: หัว=3♣ มีคนทิ้ง 4♣ แล้วมีคนเก็บไปเกิด 2♣-3♣-4♣ (2♣=สเปโต, 3♣=หัว) → คนทิ้ง 4♣ โดนปี้ทั้งหัว+สเปโต
- **โดนทั้งคู่ → จ่ายคนอื่นคนละ −2 | โดนอย่างเดียว → คนละ −1**
- **มีผลแค่ 1 ตา (turn)** ✅

### 9.3 โง่ (ทิ้งให้คนถัดไปน็อค) — คนโง่จ่ายแทนทั้งวง + วนทิศ!

> 💡 **หลักการ:** เมื่อโง่ คนน็อคได้คะแนนน็อคตามปกติ แต่ **คนโง่เป็นคนจ่ายแทนผู้เล่นทุกคนทั้งวง** → ผู้เล่นคนอื่น **ไม่เสีย** คนโง่รับเต็มคนเดียว ✅

| กรณี | คนโง่จ่าย | คนน็อคได้ | ผู้เล่นคนอื่น |
|------|-----------|-----------|-------------|
| **โง่** (ทิ้งให้น็อค) | **−6** | **+6** | 0 |
| **โง่มืด** (น็อคมืด) | **−6 ×2 = −12** | +12 | 0 |
| **โง่มืดจนชนมืด** | **−6 ×2 ×2 = −24** | +24 | 0 |

- **โง่มืดจนชนมืด** = ทิ้งไพ่แล้วคนถัดไป **น็อคมืดตั้งแต่ต้นรอบ** (น็อคมืดในตาแรกที่มีโอกาส) ✅
- **เมื่อเกิดโง่ → ทิศทางการเล่นวนกลับด้าน** ✅

### 9.4 อมสเปโต (ถือสเปโตไม่ลงจนจบรอบ) — คิดตอนจบรอบ
- จบรอบแล้วยังถือ **สเปโต (2♣ / Q♠)** ในมือ ไม่ได้เกิด/ฝาก
- นับ **50 แต้มค้างมือ** (สำหรับจัดอันดับ) ตามปกติ
- **ปรับเพิ่ม: ผู้อม −3 คะแนน / ผู้เล่นคนอื่น +คนละ 1** ✅ (ต่อสเปโต 1 ใบ)
