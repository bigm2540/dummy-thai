# Feature List แยกตาม Role — เกมดัมมี่กินเงินไทย

> **เฟส 0 (ต่อ)** — แจกแจงฟีเจอร์ตามบทบาท เพื่อกำหนดขอบเขตงาน
> ลำดับความสำคัญ: 🟢 MVP (เฟส 1 ต้องมี) · 🟡 ควรมี · ⚪ ไว้ทีหลัง
> อ้างอิง: [01](01-กติกาเกม.md) · [02](02-ออกแบบ-data-model.md) · [04](04-ออกแบบหน้าจอ.md)

---

> 📌 **ขอบเขต:** เกมนี้เป็น **"ตัวนับแต้ม + สรุปยอดเงิน"** ให้เพื่อนเคลียร์กันเอง — **ไม่มีระบบรับ-โอนเงินจริงในแอป** (เลี่ยงประเด็นพนันออนไลน์)

## บทบาททั้งหมด
1. **ผู้เล่น (Player)** — ทุกคนในห้อง (รวมเจ้าของห้องด้วย)
2. **เจ้าของห้อง (Host / แอดมิน)** — ผู้สร้างห้อง มีสิทธิ์จัดการห้อง (เป็นผู้เล่นด้วย)
3. **เจ้ามือ (Dealer)** — บทบาทหมุนเวียนต่อรอบ (ระบบจัดการให้)
4. **ระบบ/เซิร์ฟเวอร์ (System)** — ไม่ใช่คน แต่คือฟีเจอร์ที่ต้องทำงานเบื้องหลัง

---

## 1. ผู้เล่น (Player)

### ก่อนเล่น (ล็อบบี้/ห้องรอ)
| ฟีเจอร์ | ระดับ |
|--------|------|
| ตั้งชื่อผู้เล่น | 🟢 |
| เข้าห้องด้วยรหัส | 🟢 |
| ดูที่นั่ง/ผู้เล่นในห้อง + สถานะพร้อม | 🟢 |
| ออกจากห้อง | 🟢 |
| กลับเข้าเกมหลังหลุดเน็ต/รีเฟรช (reconnect ด้วย token) | 🟢 |
| แชท / อิโมจิในเกม | ⚪ |

### ขณะเล่น (ในตาตัวเอง)
| ฟีเจอร์ | ระดับ |
|--------|------|
| จั่วไพ่จากกองจั่ว | 🟢 |
| เก็บไพ่จากกองทิ้ง (เก็บกอง — ขุดได้) | 🟢 |
| เกิด (ลงตอง/เรียง) | 🟢 |
| เกิดหัว (ดึงไพ่หัวมาเกิด) | 🟢 |
| ฝากเข้าชุดตัวเอง/คนอื่น | 🟢 |
| ฝากสเปโต (ได้/ทำคนอื่นเสีย) | 🟢 |
| ทิ้งไพ่ | 🟢 |
| น็อค (รวม น็อคมืด/สี/มืดสี) | 🟢 |
| โชว์สเปโตครบ 2 ใบ (ตอนเริ่มรอบ) | 🟡 |

### ดูข้อมูล (ตลอดเกม)
| ฟีเจอร์ | ระดับ |
|--------|------|
| เรียง/จัดไพ่ในมือตัวเอง | 🟢 |
| ดูกองทิ้งทุกใบ + ไพ่หัว (มงกุฎ) | 🟢 |
| ดูชุดที่เกิดของทุกคน (แยกโซนเจ้าของ) | 🟢 |
| ดูจำนวนไพ่ในมือคนอื่น + แต้ม/คะแนน | 🟢 |
| ดูว่าตาใคร + เวลานับถอยหลัง | 🟢 (เวลา 🟡) |
| ดูหน้าสรุปท้ายรอบ | 🟢 |
| ดูคะแนน/เงินสะสมของทุกคน | 🟢 |
| **กดดูตารางคะแนน+เงินรวมสด ได้ทุกเมื่อระหว่างเล่น** | 🟢 |
| **ดูประวัติการคิดคะแนน** (แตะดูว่าใครได้/เสียมาจากเหตุการณ์อะไรบ้าง — กันทะเลาะ) | 🟢 |

---

## 2. เจ้าของห้อง (Host / แอดมิน)
*(ทำได้ทุกอย่างของผู้เล่น + เพิ่มเติม)*

| ฟีเจอร์ | ระดับ |
|--------|------|
| สร้างห้อง + สร้างรหัสห้อง | 🟢 |
| ตั้งเรทเงิน (บาท/คะแนน) | 🟢 |
| เริ่มเกม (เมื่อครบ 4 คน) | 🟢 |
| เริ่มรอบใหม่ (หลังหน้าสรุป) | 🟢 |
| ปิดห้อง → สรุปเงินรวมจบแมตช์ | 🟢 |
| จัดการผู้เล่นที่หลุดเกิน grace (รอต่อ / จบแมตช์) | 🟢 |
| ตั้งค่าคะแนน custom (+6/−1−2−3, ตัวคูณ, โบนัส, บทลงโทษ) | 🟡 *(ใช้ค่า default ก่อนได้)* |
| ตั้งเวลาต่อตา (ปิด/30/60 วิ) | 🟡 |
| เตะผู้เล่น / ล็อกที่นั่ง | ⚪ |

---

## 3. เจ้ามือ (Dealer) — บทบาทหมุนเวียนต่อรอบ

> เป็นบทบาทเชิงกติกา ระบบจัดการให้ ไม่มีปุ่มพิเศษที่ผู้เล่นกดเอง

| ฟีเจอร์ | ระดับ |
|--------|------|
| เป็นคนที่ระบบแจกไพ่เริ่มจาก | 🟢 |
| เล่นเป็นคนแรกของรอบ | 🟢 |
| หมุนเจ้ามือไปคนถัดไปทุกรอบ | 🟢 |

---

## 4. ระบบ/เซิร์ฟเวอร์ (System) — เบื้องหลัง (server-authoritative)

| ฟีเจอร์ | ระดับ |
|--------|------|
| สร้าง/สับสำรับ + แจกไพ่ + เปิดไพ่หัว | 🟢 |
| ตรวจทุก action ว่าถูกกติกา (กันโกง) | 🟢 |
| คำนวณ `allowedActions` (ปุ่มที่กดได้) ส่งให้ client | 🟢 |
| สร้าง PlayerView (ซ่อนมือคนอื่น + กองจั่ว) | 🟢 |
| ตรวจชุดถูกต้อง (ตอง/เรียง, A สูง) + กฎเก็บกอง | 🟢 |
| คิดแต้มสุทธิ + จัดอันดับเสียน้อย/กลาง/มาก (เท่ากันสุ่ม) | 🟢 |
| คิดคะแนน + ตัวคูณน็อค + โบนัส (หัว/สเปโต/โชว์/ใบปิด) | 🟢 |
| ตรวจจับ + คิดบทลงโทษ: โง่ (จ่ายรอบวง+วนทิศ), ปี้, ทิ้งดัมมี่/เต็ม | 🟢 |
| จัดการทิศทางการเล่น (โง่ = กลับทิศ) | 🟢 |
| บันทึก ScoreEvent + สร้างหน้าสรุปรอบ + สรุปเงินรวม | 🟢 |
| แสดงเอฟเฟกต์เหตุการณ์ (เด้ง "−50P" ฯลฯ) | 🟡 |
| จับเวลาต่อตา + auto (จั่ว+ทิ้ง) เมื่อหมดเวลา | 🟡 |
| จัดการหลุด/รอ grace/reconnect ด้วย token + popup host | 🟢 |
| กองจั่วหมด → จบรอบ | 🟢 |
| เซฟ state ภายนอก (DB/Redis) กันเซิร์ฟเวอร์หลับ/รีสตาร์ท | 🟡 |
