# 🃏 ดัมมี่กินเงินไทย (ออนไลน์)

เกมไพ่ดัมมี่ไทย เล่นกับเพื่อน 4 คน ผ่านเว็บ/มือถือ

## เอกสาร
อยู่ในโฟลเดอร์ [`docs/`](docs/) — กติกา, data model, โครงสร้าง, หน้าจอ, ฟีเจอร์, แผนเฟส 1, การคิดเงิน

## ติดตั้ง
```bash
npm install
```

## คำสั่ง
| คำสั่ง | ทำอะไร |
|-------|--------|
| `npm test` | รันชุดทดสอบ game logic |
| `npm start` | รันเซิร์ฟเวอร์ (ยังไม่พร้อม — M5) |
| `npm run dev` | รันแบบ auto-restart (ยังไม่พร้อม — M5) |
